WARP

Бесплатный туннель Cloudflare для сервисов, которые сами закрыли доступ из вашего региона: нейросети, музыка, загрузки программ. Через WARP идут только выбранные сервисы, остальное — напрямую.

Что пускать через WARP

Свои сайты

По одному домену в строке, поддомены учитываются автоматически.

Параметры

Порт локального прокси
По умолчанию 40080. Браузеры получают его автоматически через системные настройки прокси

Диагностика

Проверка того, что именно мешает: подмена DNS, блокировка по IP, обрыв соединения или ограничение самого сервиса. Займёт около 20 секунд.

Telegram

Встроенный прокси для приложения Telegram Desktop. Трафик идёт к серверам Telegram через WebSocket, обход для этого не нужен.

Нажмите «Подключить» и подтвердите в Telegram. Это нужно сделать один раз.

Параметры

Порт
По умолчанию 1443. После смены порта заново подключите прокси в Telegram

Папка с данными

          


          
Zapret2 GUI использует zapret2 (bol-van, MIT), драйвер WinDivert. Прокси для Telegram — собственная реализация протокола tg-ws-proxy (Flowseal, MIT); как запасной путь он использует Cloudflare-серверы проекта tg-ws-proxy. Антивирусы иногда ошибочно считают WinDivert опасным: это драйвер перехвата пакетов, а не вирус. Исходный код: raiyaxkrash/zapret2-rust.
