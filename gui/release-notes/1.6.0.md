## Zapret2 GUI 1.6.0: хостинги, подсказка по провайдеру, мастер настройки

Скачайте установщик `*-setup.exe` ниже. Установленное приложение обновится само.

### Новое

**Набор «Зарубежные хостинги и CDN».** Для сайтов и игр, которые обрываются или грузятся бесконечно, потому что размещены на Cloudflare, Hetzner, DigitalOcean, OVH, AWS, Google Cloud, Oracle и других хостингах. Блокируют их по IP, поэтому набор работает по списку подсетей (около 16 тысяч, из открытой базы RIPEstat). Обход применяется только к TLS на порту 443, сайты из «Исключений» не затрагиваются. Быстрая проверка и автоподбор теперь проверяют и хостинги.

**Стратегия под провайдера.** На странице «Стратегии» видно, кто ваш провайдер. Если для него известна рабочая стратегия, её можно применить одной кнопкой. После подбора появилась кнопка «Поделиться результатом»: она открывает на GitHub заполненное сообщение (провайдер и стратегии). Из этих результатов собираются рекомендации для всех.

**Мастер первого запуска.** Три шага: что у вас не открывается → настройка (рекомендация для провайдера или автоподбор) → итог. Пройти заново можно в «Настройки → Дополнительно».

### Изменено

- Главная стала проще: кнопка включения, доступность, сервисы и Telegram.
- «Наборы сайтов» и режим «Моих сайтов» перенесены на страницу «Списки сайтов», переключатель QUIC — на страницу «Стратегии».
