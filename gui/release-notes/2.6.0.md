## Zapret2 GUI 2.6: WARP заработал в России

Скачайте установщик `*-setup.exe` ниже. Установленное приложение обновится само.

### Новое

**WARP сам подбирает способ подключения.** Российские провайдеры режут рукопожатие WARP, а иногда пропускают его и обрывают данные. Теперь Zapret2 пробует точки подключения и способы маскировки (случайные пакеты, маскировка под DNS или QUIC, без маскировки) и каждый проверяет настоящей загрузкой через туннель. Рабочий способ запоминается и используется дальше. Если связь пропадёт, программа сначала попробует прежний способ, потом подберёт заново. Проверено через московского провайдера: WARP подключается и выдаёт около 18 Мбит/с.

**WARP через обход.** Когда обход включён, zapret2 узнаёт рукопожатие WARP и маскирует его под DNS, а регистрация WARP, адрес которой провайдеры блокируют, проходит через обход. Если WARP не смог подключиться, он попробует ещё раз сразу после включения обхода.

На странице WARP видно, каким способом он подключён. В режиме для опытных появилась кнопка «Подобрать заново».

### Важно: что WARP может и чего не может

Проверка через российского провайдера показала: **ChatGPT, Claude, Spotify и другие сервисы, которые сами закрыли доступ из России, через WARP не откроются.** Cloudflare намеренно показывает сайтам настоящую страну пользователя, и OpenAI отвечает «страна не поддерживается». Раньше Zapret2 обещал обратное — это была ошибка, простите.

Поэтому:
- из мастера первого запуска убран пункт «Нейросети», а со страницы WARP — наборы «Нейросети», «Музыка» и «Программы и разработка»;
- WARP теперь описан честно: это туннель для сайтов, которые провайдер блокирует так, что обход их не открывает. Сайты для него задаются своим списком;
- диагностика больше не советует WARP для ChatGPT: для сервисов, закрытых по стране, нужен VPN с сервером за границей.
