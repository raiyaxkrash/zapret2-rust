## Zapret2 GUI 2.3: WARP для программ и новая иконка

Скачайте установщик `*-setup.exe` ниже. Установленное приложение обновится само.

### Новое

**WARP для программ.** Раньше через WARP шли только браузеры: они берут настройки прокси из Windows. Теперь через WARP идут и программы, которые эти настройки не используют: Spotify, ChatGPT и Claude для компьютера и другие. Пакеты к выбранным сайтам перехватывает тот же драйвер WinDivert, что работает у zapret2, и отправляет их в туннель. Остальной трафик идёт напрямую, как раньше.

Включено по умолчанию. Выключается на странице WARP переключателем «Для программ». Если программа была открыта до включения WARP, перезапустите её.

**Новая иконка** в стиле приложения: белая сфера с буквой Z.
