## Zapret2 GUI 1.5.0: прокси для Telegram Desktop

Скачайте установщик `*-setup.exe` ниже. Установленное приложение обновится само.

### Новое

**Прокси для Telegram Desktop.** На главной странице появился раздел «Telegram» с переключателем «Прокси для Telegram Desktop». Приложение Telegram начинает работать даже там, где оно не подключается напрямую. Настраивать обход и стратегии для этого не нужно.

- Включите переключатель и нажмите «Подключить в Telegram». Telegram сам предложит добавить прокси, это нужно сделать один раз.
- Кнопка «Скопировать ссылку» нужна, если Telegram не открылся сам: отправьте ссылку себе в Telegram и откройте её.
- Прокси работает отдельно от обхода: его можно включить, даже если обход выключен.
- Порт по умолчанию 1443, его можно сменить в «Настройки → Дополнительно».

### Как это работает

- Встроенный локальный MTProto-прокси на `127.0.0.1`. Это собственная реализация на Rust протокола [tg-ws-proxy](https://github.com/Flowseal/tg-ws-proxy) (Flowseal, MIT). Python и отдельные программы не нужны, установщик почти не вырос.
- Трафик Telegram идёт к его серверам через WebSocket поверх TLS. Если прямое подключение блокируется, приложение пробует подключение с подменой имени сервера (SNI).
- Запасные пути: Cloudflare-серверы проекта tg-ws-proxy (их список обновляется с GitHub раз в час), затем прямое TCP-подключение.
- Секрет прокси создаётся при первом включении и больше не меняется, поэтому подключать прокси в Telegram заново не нужно.
- В журнал с пометкой `[tg]` пишется, каким путём идёт каждый дата-центр (например, «DC1: через Cloudflare»), а также ошибки и сводка раз в 10 минут. Секрет в журнал не попадает.

### Проверено

- Через прокси получены ответы от серверов Telegram из всех дата-центров (DC1–DC5, включая медиа).
- Шифрование сверено с оригинальным tg-ws-proxy.
