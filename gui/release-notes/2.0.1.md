## Zapret2 GUI 2.0.1

Скачайте установщик `*-setup.exe` ниже. Установленное приложение обновится само.

### Исправлено

- Кнопка «Поделиться результатом» после подбора стратегии теперь открывает на GitHub готовую форму «Стратегия для провайдера» с уже заполненными полями: провайдер, номер AS, стратегии и версия приложения. Раньше открывался выбор шаблона, и данные терялись. Из таких сообщений собираются подсказки «Для вашего провайдера обычно работает…».
- На странице «Стратегии» убрана последняя цветная иконка, выбивавшаяся из чёрно-белого дизайна.
