## Zapret2 GUI 2.4: своя стратегия для каждой сети

Скачайте установщик `*-setup.exe` ниже. Установленное приложение обновится само.

### Новое

**Своя стратегия для каждой сети.** У разных провайдеров разные блокировки: дома работает одна стратегия, через раздачу с телефона другая. Zapret2 запоминает, какая стратегия работала в каждой сети. Когда ноутбук переходит в другую сеть, нужная стратегия включается сама, без нового подбора. Выключается в Настройках → Сторож → «Помнить стратегию для каждой сети».

**История стратегий.** На странице «Стратегии» видно, какие стратегии были в текущей сети, откуда взялась каждая (подбор, выбрана вручную, возврат) и когда. Любую из них можно вернуть одной кнопкой.

**Откат после неудачного переподбора.** Если сторож подобрал новую стратегию, а с ней открывается меньше сервисов, чем с прежней, он возвращает прежнюю.
